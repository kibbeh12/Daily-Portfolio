# Daily Portfolio

تطبيق بسيط وأنيق لمتابعة المصروفات اليومية.

## Features

- شاشة إعداد أولية لاختيار اللغة والعملة
- بحث سريع داخل قائمة العملات
- تسجيل مصروفات اليوم مع التواريخ
- ملخص يومي وشهري
- حفظ البيانات محليًا على الجهاز
- تصميم هادئ باللون الذهبي والأسود

## Requirements

- Flutter SDK
- Android Studio
- Android SDK

## Run locally

```bash
flutter pub get
flutter run
```

## Build APK

```bash
flutter build apk --release
```

The APK will be generated in: `build/app/outputs/flutter-apk/app-release.apk`
